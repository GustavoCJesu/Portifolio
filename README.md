# 💻 Portfólio — Gustavo Jesuino

Site de portfólio pessoal, desenvolvido do zero com HTML, CSS e JavaScript puro, reunindo minha trajetória, experiência, projetos e formação como desenvolvedor Fullstack.

🔗 **Demo ao vivo:** [gustavocjesu.github.io/Portifolio](https://gustavocjesu.github.io/Portifolio/)

## ✨ Funcionalidades

- **Seção Sobre**: apresentação pessoal e cards de estatísticas (tempo de estudo, projetos, tecnologias).
- **Competências técnicas** organizadas por categoria (Frontend, Backend, Banco de Dados, Ferramentas).
- **Trajetória profissional e acadêmica** em formato de linha do tempo.
- **Vitrine de projetos**, com status (concluído / em desenvolvimento) e tecnologias usadas em cada um.
- **Formação acadêmica** em cards.
- **Seção de contato** com links diretos para e-mail e LinkedIn.
- **Animações de entrada** ao rolar a página, usando `IntersectionObserver` (JavaScript puro, sem dependências).
- Layout **100% responsivo**.

## 🛠️ Tecnologias

- **HTML5** semântico
- **CSS3** (Flexbox / Grid, sem frameworks)
- **JavaScript** vanilla (animações de scroll com `IntersectionObserver`)

## 🚀 Como rodar localmente

Por ser um site 100% estático, basta abrir o arquivo diretamente no navegador:

```bash
# Clonar o repositório
git clone https://github.com/GustavoCJesu/Portifolio.git
cd Portifolio

# Abrir index.html no navegador
# ou, opcionalmente, servir com um servidor local:
npx serve .
```
